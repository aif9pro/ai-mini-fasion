# 分镜与 Prompt 规则

## 固定五镜头

必须生成以下五种不同景别，顺序固定：

1. `extreme_long_shot`：远景，交代人物与环境关系、空间规模和叙事位置；人物占画面比例较小，但固定轮廓或服装色彩仍需可辨识。
2. `long_shot`：全景，展示人物完整身体、整体造型、站姿或行走动作；强调服装廓形与身体比例。
3. `medium_shot`：中景，通常取胸部或腰部以上；强调人物与环境的互动、手势、姿态和造型细节。
4. `close_up`：近景，通常取肩部或胸部以上；强调脸部、眼神、发型、妆容和标志性特征。
5. `extreme_close_up`：特写，聚焦眼睛、眉尾小痣、首饰、面料纹理或其他已存在的固定识别点；不得凭空增加新的身份特征。

## 一致性锁定

将以下信息复制或等义保留在每个 Prompt 中：

- `role.name`、`role.type`、`age_stage`、`age_range`、`gender_expression`
- `role.appearance.face`、`hair`、`body`、`signature_features`
- `role.styling.clothing`、必要的 `makeup_hair` 和 `accessories`
- `role.consistency.fixed`
- 用户硬约束及不得改变的身份信息

允许变化的内容只来自镜头景别、构图、动作、表情、场景可见范围、视线和叙事重点。除非 `role.consistency.variable` 或用户要求允许变化，不改变服装、发型、年龄和固定锚点。

## Prompt 顺序

按以下顺序编排每条 Prompt：

```text
角色一致性前缀 → 景别与构图 → 姿态/动作/表情 → 可见服装与细节 → 场景叙事 → 光线与画面用途 → 质量约束
```

`prompt` 使用适合通用图像模型的完整描述；`prompt_zh` 使用中文，保留同等视觉信息；不要添加平台专属参数。

## 负向 Prompt

每个镜头都应包含与景别相关的负向约束，并至少覆盖：人物身份漂移、不同发型、年龄变化、重复人物、脸部变形、肢体结构错误、额外手指、文字水印和低清晰度。远景重点补充比例错误和人物缺失，近景/特写重点补充五官变形、皮肤塑料感和固定识别点丢失。
