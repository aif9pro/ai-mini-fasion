# 通用 Prompt 规则

## 组织顺序

按以下顺序组织 `prompt`：

```text
人物身份与年龄 → 核心外观 → 稳定识别锚点 → 性格气质 → 服装造型 → 姿态行为 → 场景叙事 → 画面用途与技术要求
```

Prompt 必须保留用户硬约束，不得加入会改变人物身份的未要求种族、年龄、性别表达、身体特征、时代或职业设定。

## 输出原则

- 使用清晰、具体、可观察的描述。
- 默认使用用户输入的语言，不为特定平台改写格式、语言或参数。
- 不添加平台专属后缀、版本号、比例参数或模型参数。
- `negative_prompt` 只写需要避免的错误，不重复大段正向描述。

## 负向约束

根据人物需要在 `negative_prompt` 中加入结构错误、身份漂移、发型漂移、重复人物、廉价塑料质感、脸部变形、手部错误等约束。不得用负向 Prompt 覆盖用户的正向硬约束。
